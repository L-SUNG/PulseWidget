Pulse Widget 사용 안내

위젯을 클릭하면 사용량 상세와 설정을 볼 수 있습니다.
위젯 또는 트레이 아이콘을 우클릭하면 위치, 테마, 디스플레이, 자동 실행을 변경할 수 있습니다.

OpenAI 사용량은 이 PC에 로그인한 Codex 계정에서 읽습니다.
Claude Desktop 사용량은 이 PC의 앱이 저장한 기록에서 읽습니다.
계정 로그인 정보나 다른 PC의 사용량 기록은 설치 파일에 포함되지 않습니다.

기존 위치, 테마, 사용자 색상, 디스플레이 설정은 업데이트 후에도 유지됩니다.
Windows 설정의 '설치된 앱'에서 Pulse Widget을 제거할 수 있습니다.
제거 후에도 %LOCALAPPDATA%\PulseWidget의 설정과 사용량 기록은 남습니다.

설치 프로그램은 Claude Code 설정을 자동으로 변경하지 않습니다.
기존에 설치한 Claude Code 연동도 유지됩니다. 연동을 해제하려면 프로그램 제거 전에
설치 폴더의 scripts\Uninstall-Claude.ps1을 실행하세요.
